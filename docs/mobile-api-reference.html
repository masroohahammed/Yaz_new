Authentication

GET /health Public

Health Check — Health check for load balancers, mobile startup, and monitoring. Confirms the API router is reachable.

HTTP: 200 OK

Input
None
Response example
{
  "status": true,
  "message": "API is healthy"
}
cURL
curl -X GET '{{BASE_URL}}/health' \
  -H 'Accept: application/json'
POST /auth/login Public

Login — Authenticate with email and password. Returns a session token valid for 24 hours (stored in user_sessions).

HTTP: 200 OK

Request JSON
{
  "email": "user@example.com",
  "password": "your-password"
}
Response example
{
  "status": true,
  "message": "Login successful",
  "token": "a1b2c3d4e5f6789012345678901234567890abcdef1234567890abcdef123456",
  "user": {
    "id": 1,
    "name": "Ahmed Ali",
    "email": "user@example.com",
    "role": "facility_manager"
  }
}
cURL
curl -X POST '{{BASE_URL}}/auth/login' \
  -H 'Content-Type: application/json' \
  -d '{'email':'user@example.com','password':'your-password'}'

POST /app-log Public

App Log — Log mobile app events (splash screen, errors, CTA clicks) to app_mobile_logs.

HTTP: 200 · 400 validation · 401 unauthorized · 403 forbidden

Request JSON
{
  "action": "splash_loaded",
  "status": "success",
  "message": "App opened",
  "app_version": "1.2.0",
  "platform": "android",
  "user_id": 0,
  "context": {
    "screen": "home"
  }
}
Response example
{
  "status": true,
  "message": "Logged"
}
