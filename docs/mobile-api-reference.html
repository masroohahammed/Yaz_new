Al Yazwa FM — Mobile API Reference

REST API v1 · Postman import · cURL · JSON examples

Base URL{{BASE_URL}} e.g. https://pfms.alyazwa.com/api/v1
AuthAuthorization: Bearer <token> from POST /auth/login
Content-Typeapplication/json
Token lifetime24 hours
Mobile app flow
  1. GET /health — verify API is reachable
  2. POST /auth/login — store bearer token
  3. GET /auth/me — restore session, read role / app_area
  4. Route to Tenant, FM, or Employee screens
Sections
  • Authentication
  • Tenant Portal
  • Facility Management
  • Employee Self-Service
  • Properties, Finance & Logging
Postman: Copy any cURL block below → Import → Raw text. Set variables BASE_URL and TOKEN.

Authentication

GET /health Public

Health Check — Health check for load balancers, mobile startup, and monitoring. Confirms the API router is reachable.

Auth: None

Input
None
Response example
{
  "status": true,
  "message": "API is healthy"
}
cURL — paste into Postman Import → Raw text
curl -X GET "{{BASE_URL}}/health" \
  -H "Accept: application/json"
POST /auth/login Public

Login — Authenticate with email and password. Returns a session token valid for 24 hours (stored in user_sessions).

Auth: None

Request JSON
{
  "email": "user@example.com",
  "password": "your-password"
}
Response example
{
  "status": true,
  "message": "Login successful",
  "token": "a1b2c3d4e5f6789012345678901234567890abcdef1234567890abcdef123456",
  "user": {
    "id": 1,
    "name": "Ahmed Ali",
    "email": "user@example.com",
    "role": "facility_manager"
  }
}
cURL — paste into Postman Import → Raw text
curl -X POST "{{BASE_URL}}/auth/login" \
  -H "Content-Type: application/json" \
  -d '{"email":"user@example.com","password":"your-password"}'
