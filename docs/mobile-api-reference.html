Replace before calling

{{BASE_URL}} — API base, e.g. https://your-domain.com/public/api/v1

{{PUBLIC_BASE}} — Site root, e.g. https://your-domain.com/public

{{TOKEN}} — Session token from POST /auth/login (Authorization: Bearer …, valid 24h)

Original mobile app flow

  1. Startup — GET /api/v1/health then optional POST /api/v1/app-log (splash / telemetry)
  2. Login — POST /api/v1/auth/login → store token
  3. Profile — GET /api/v1/auth/me → read role and route UI
  4. FM roles (facility_manager, supervisor, technician) — /fm/dashboard, work orders, complaints, job cards, technicians
  5. Tenant role — /portal/contracts, payments, service requests, document download
  6. Properties — list + KPIs for assigned facilities
  7. Inspections — property / unit compliance lists and detail
  8. Public — guest maintenance submit + ticket tracking (no token)
Import into Postman: Click Import → Raw text and paste any cURL block below. Postman converts it to a ready request. Set collection variables BASE_URL and TOKEN to avoid editing each request.

System

GET /api/v1/health

Health check for load balancers, mobile startup, and monitoring. Confirms the API router is reachable.

Auth: None

cURL — Postman import

curl -X GET "{{BASE_URL}}/health" \
  -H "Accept: application/json"

Request body (JSON)

None

Response example

{
  "status": true,
  "message": "API is healthy"
}

Authentication

POST /api/v1/auth/login

Authenticate with email and password. Returns a session token valid for 24 hours (stored in user_sessions).

Auth: None

cURL — Postman import

curl -X POST "{{BASE_URL}}/auth/login" \
  -H "Content-Type: application/json" \
  -d '{"email":"user@example.com","password":"your-password"}'

Request body (JSON)

{
  "email": "user@example.com",
  "password": "your-password"
}

Response example

{
  "status": true,
  "message": "Login successful",
  "token": "a1b2c3d4e5f6789012345678901234567890abcdef1234567890abcdef123456",
  "user": {
    "id": 1,
    "name": "Ahmed Ali",
    "email": "user@example.com",
    "role": "facility_manager"
  }
}

Auth: Bearer JWT (finance role)

cURL — Postman import

curl -X GET "{{BASE_URL}}/finance/reconciliation?from=2026-09-01&to=2026-09-11" \
  -H "Authorization: Bearer {{TOKEN}}"

Request body (JSON)

None

Response example

{
  "status": true,
  "from": "2026-09-01",
  "to": "2026-09-11",
  "activity": [],
  "total_in": 25000,
  "total_out": 8000,
  "net": 17000
}

Public (no login)

POST /api/public/maintenance

Submit a public maintenance request without authentication. Returns a ticket number for tracking.

Auth: None

cURL — Postman import

curl -X POST "{{PUBLIC_BASE}}/api/public/maintenance" \
  -H "Content-Type: application/json" \
  -d '{"requester_name":"John Doe","description":"Water leak in lobby","facility_id":12,"priority":"high"}'

Request body (JSON)

{
  "requester_name": "John Doe",
  "description": "Water leak in lobby",
  "facility_id": 12,
  "category": "Plumbing",
  "priority": "high"
}

Response example

{
  "status": true,
  "ticket_number": "MR-2026-0016",
  "message": "Request submitted successfully"
}

GET /api/public/track/{ticket}
