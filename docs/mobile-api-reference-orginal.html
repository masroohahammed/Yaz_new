Authentication

GET /health Public

Health Check — Verify the API is deployed and reachable before testing login. No authentication required.

HTTP: 200 OK

Input
None
Response example
{
  "status": true,
  "message": "Al Yazwa FM API v1 is reachable",
  "version": "2.5.1",
  "login": {
    "method": "POST",
    "url": "https://pfms.alyazwa.com/api/v1/auth/login"
  }
}
cURL
curl -X GET 'https://pfms.alyazwa.com/api/v1/health' \
  -H 'Accept: application/json'
POST /auth/login Public

Login — Authenticate a user with email and password. Returns a bearer token (valid 24 hours) and user profile including app_area for mobile routing.

HTTP: 200 · 400 missing fields · 401 invalid credentials · 503 user_sessions table missing

Request JSON
{
  "email": "user@example.com",
  "password": "your-password"
}
Response example
{
  "status": true,
  "message": "Login successful",
  "token": "a1b2c3d4e5f6...",
  "user": {
    "id": 1,
    "name": "Ahmed Hassan",
    "email": "user@example.com",
    "phone": "+97455551234",
    "role": "technician",
    "role_display": "Technician",
    "workspace": "fm",
    "app_area": "fm",
    "company_id": 1,
    "tenant_id": null,
    "employee_id": 12
  }
}
cURL
curl -X POST 'https://pfms.alyazwa.com/api/v1/auth/login' \
  -H 'Accept: application/json' \
  -H 'Content-Type: application/json' \
  -d '{
  "email": "user@example.com",
  "password": "your-password"
}'
